Solution Implemented
Temporary Table Strategy:
def create_temp_table():
    """Create temp table for faster pattern execution"""
    # Drop existing temp table
    drop_sql = "DROP TABLE IF EXISTS gbi_fraud_bap_db.ai_live_biz_app.trader_temp_frame"
    sf.run_query(drop_sql)
    
    # Create temp table with 5-day rolling window
    sql = """
    CREATE TEMP TABLE trader_temp_frame AS
    SELECT *
    FROM gbi_fraud_bap_db.ai_live_biz_app.Trader_TFA_traderhunt_frame
    WHERE EVENT_TS >= current_date - 5
    """
    
    start_time = time.time()
    sf.run_query(sql)
    duration = time.time() - start_time
    print(f"Temp table created in {duration:.2f}s")
    return duration

Query Transformation Update:

Key Design Decisions:
1. 5-Day Rolling Window: Recent data only (fraud detection needs fresh data)
2. Temp Table vs Persistent: Temp table auto-cleans, no storage management needed
3. Single Scan: Create once per run, reference 20+ times
4. Cleanup: DROP TABLE IF EXISTS in finally block ensures no orphaned tables
