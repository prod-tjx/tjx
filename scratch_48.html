How AutoCT Works — Two Jobs, One Pipeline

1Build Frame

FF-exclusion JOIN against tfa_aso_freight_forwarder_address_log on APPLE_MAPS_ADD. 5-day lookback.

2Read SQL Patterns

Glob active_queries/*.sql. Strip CREATE OR REPLACE VIEW … AS wrapper, swap source tables to temp frame.

3Classify TH vs GCT

Filename heuristic + per-file override comment -- query_type: GCT. Drives ACTION_LEVEL mapping.

4Execute & Enrich

Each pattern joins back to temp frame for full 50+ column enrichment. Results aggregated, deduped on order_identifier.

5Write Results Table

TRUNCATE + write_pandas into Trader_Automated_Queries_Results. Optional logging-table append.

6AutoCT Executor

Pulls TH-only backlog filtered by ASO ST-block + no prior D68 action. Generates A3 token via IDMS.

7ACM Mass Action

Per-pattern TRADERCONFIRM / A101 in 500-order batches. Per-order case note: SDS Trader Confirm SL TH - "<pattern>".

8Slack Notify

Green-bar summary on success only. Silent on empty backlog or failure (per design — mirrors ASO health monitor).
