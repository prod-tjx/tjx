Use Pandas to combine and clean data from many sources

MODULES 2 & 3

What the course taught

Pandas gives you a spreadsheet you can control with code. The key moves:

  • concat — stack tables on top of each other
  • drop_duplicates — remove repeated rows
  • groupby — group rows by a column
  • Filtering with simple true/false rules

How I used it

My pipeline can run 15+ different SQL queries, each looking for a different type of suspicious order. Today, 2 patterns are live and more are queued up to add.

I stack all the results into one big table, drop any order that appears in more than one query, and save the clean list back to Snowflake.

What it produced

One clean table of unique orders, ready for the next step in the pipeline to act on.

Built for 15+ queries 2 patterns live today 0 duplicate orders
Combining results from many queries into one clean table
Python
# Start with an empty list to collect results from every query
all_results = []

# Loop through each .sql file in the active_queries folder
for query in sql_files:

    # Run the query against Snowflake — returns a Pandas DataFrame
    # (a DataFrame is basically a table with rows and columns)
    df = run_query(query)

    # Skip queries that found nothing — no point keeping empty tables
    if not df.empty:
        all_results.append(df)

# Stack every result on top of each other into one big table
# Example: query A finds 100 orders, query B finds 50 → combined has 150 rows
combined = pd.concat(all_results)

# Remove any order_id that appears more than once
# (an order might be flagged by 2+ patterns — we only want it listed once)
combined = combined.drop_duplicates(subset=["order_id"])

# Write the final clean table back to Snowflake for the next step to use
write_to_snowflake(combined)
